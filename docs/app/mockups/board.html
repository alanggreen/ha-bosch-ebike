Departure board

Every link is a row on one ruled board, problems first. The Ride screen speaks the same language with flip cells. No cards, no tiles. Mockup with synthetic data; use the buttons to change the situation.

Material 3 structure: top app bar, two-destination navigation bar, 48 dp targets. Rows are ordered by urgency, so the first row is always the thing to fix; the state cell flips once when a link changes. Marks are drawn, and every state also has words, so colour is never the only signal.
